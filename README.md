# tripleten_sprint5_projeto
Projeto sprint 5

## sobre o projeto
Este projeto desenvolve um aplicativo web utilizando Streamlit para explorar e analisar anúncios de veículos. O aplicativo permite visualizar os dados, aplicar filtros e comparar informações sobre os veículos anunciados.

## funcionalidades
Visualização da tabela completa de anúncios.
Filtros por câmbio, tipo de veículo, ano do modelo e condição.
Histograma para analisar a condição dos veículos por ano do modelo.
Histograma para comparar a distribuição de preços entre dois modelos, com opção de normalização.
Gráfico de dispersão para explorar a relação entre preço e quilometragem.

## bibliotecas utilizadas 
Pandas, Streamlit e Plotly Express.

## como executar
No terminal, execute:
python -m streamlit run app.py
